# Vector Matcher

Десктопное приложение для семантического сопоставления (матчинга) текстовых данных с использованием нейросетевых моделей и векторных эмбеддингов.

## Возможности
* Поиск наиболее подходящих записей по смыслу (а не по точному совпадению символов).
* Использование модели **BAAI/bge-m3** для генерации эмбеддингов.
* Вычисление косинусного сходства между векторами.
* Поддержка аппаратного ускорения на видеокартах NVIDIA (CUDA).
* Цветовая индикация результатов (зеленый, желтый, красный) на основе заданных порогов.
* Возможность загрузки собственной модели.
* Экспорт результатов в TSV-файл.

## Технологии
* **Язык:** Python 3.12
* **GUI:** PySide6 (Qt 6)
* **ИИ и вычисления:** PyTorch, Sentence-Transformers (BGE-M3)
* **Работа с данными:** Pandas
* **Сборка в .exe:** PyInstaller
